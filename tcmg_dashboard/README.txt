TCMG Dashboard - Starter

1) Extract the folder "tcmg_dashboard" into C:\\xampp\\htdocs\\
2) Make sure Apache is running in XAMPP.
3) Open: http://localhost/tcmg_dashboard/

This is the first visual dashboard prototype. Charts use Chart.js from a CDN,
so an internet connection is needed for the charts. The dashboard currently
uses sample/demo values; database integration and real login will be added later.
